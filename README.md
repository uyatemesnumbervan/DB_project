# DB Project — Customer & Revenue Analytics

Аналитический проект по работе с базой данных интернет-магазина.
Проект посвящён анализу клиентов, заказов, товаров, платежей и выручки с использованием SQL и Python.

* **SQLite** — база данных
* **SQL** — запросы и аналитика
* **Python** — работа с базой данных и визуализация
* **Matplotlib** — построение графиков
* **Git / GitHub** — хранение и управление проектом

Основные файлы:

* `create_DB.py` — генерация базы данных и тестовых данных;
* `DB_scripts.py` — SQL-запросы и аналитика;
* `SQL_scritps.sql` — SQL-скрипты проекта.

## Цель проекта

Проект создан для практики работы с реляционными базами данных и отработки навыков SQL, необходимых для задач **Data Analytics**.

В ходе проекта были отработаны:

* работа с несколькими связанными таблицами;
* написание сложных SQL-запросов;
* агрегация данных;
* расчёт бизнес-метрик;
* использование оконных функций;
* анализ клиентской выручки;
* визуализация результатов.
